DeepSeek Harness (`dsh`) é um harness de agentes open-source da [DeepSeek AI](https://deepseek.com), com arquitetura **tudo-é-plugin** no [Cordis](https://github.com/cordiverse/cordis).

## DeepMod — Modificações v1.0.3

- **OneBinary `DeepMod 1.0.3.exe`** — `OneBinary/electron/out/DeepMod 1.0.3.exe` (~249 MB, Electron 44, 264 pacotes) — duplo-clique e abre na tela do app, sem navegador. Sessões em `%APPDATA%\onebinary-electron\.dsh`.
- **Splash RASNER** — `Iniciando o RASNER…` + `?` tooltip, barra 0→100% com `121/121 plugins`, `Live log — avançado` + `Copiar p/ GitHub` / `Copiar p/ LLM`.
- **i18n 5 idiomas** — `en`/`zh`/`pt`/`ru`/`es` com detecção do OS e `Não perguntar novamente`.
- **Login livre** — `Add an API key` com `OpenCode Go`/`Codex`/`Outra API` + busca local `.env` no PC, sem exigir DeepSeek oficial.
- **Multi-plataforma** — GitHub Actions compila `Win (x64)`, `Linux (AppImage/deb x64/arm64)`, `macOS (dmg/zip universal)` e **auto-update** via `electron-updater` + Releases.

Veja [`CHANGELOG.md`](CHANGELOG.md) para detalhes e `OneBinary/electron/out/DeepMod 1.0.3.exe` para baixar.
